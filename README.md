# 🌊 OpenLake Website

The official web platform for **OpenLake**, the open-source community of IIT Bhilai. This website introduces visitors to our organization, showcases our technical domains and active projects, and provides beginners with interactive learning tools directly on the landing page.

---

## 🌟 Key Features

* **Interactive Tech Stack Roadmaps:** Curated learning pathways (Web Dev, App Dev, AI/ML) featuring a dynamic timeline and side-drawer modal for recommended resources.
* **"First PR" Terminal Sandbox:** An in-browser interactive terminal simulator that guides absolute beginners through core Git commands (`git clone`, `git checkout`, `git commit`, `git push`) before they contribute to real repositories.
* **Dynamic Canvas Background:** A lightweight, persistent particle animation powered by HTML5 Canvas that subtly reacts to page interactions.
* **Responsive Single-Page Architecture:** A clean, modular layout built to fit seamlessly across all device screen sizes.

---

## 🛠️ Tech Stack & Libraries

This platform is built strictly using **Vanilla Web Technologies** to ensure maximum performance, low resource overhead, and minimal external dependencies:

* **HTML5:** Semantic structure and structural accessibility.
* **CSS3:** Modern layout techniques (Flexbox, CSS Grid) with native CSS variables for glassmorphism styling and custom animations.
* **Vanilla JavaScript (ES6+):** Dynamic DOM manipulation, state management for interactive tracks/drawers, and terminal command parsing logic.
* **HTML5 Canvas API:** Used to render the interactive background particle canvas without relying on heavy external animation engines (like Three.js or Particles.js).

---

## 🎨 Design & Templates

* **Design Philosophy:** Modern Glassmorphism aesthetic using a Navy and Cyan color palette (`#001f3f` and `#00a8e8`) to represent OpenLake's brand identity.
* **Templates:** Built **100% custom from scratch**. No external pre-made UI templates, bootstrap libraries, or CSS frameworks (like Tailwind or Bootstrap) were used—giving us full control over code quality and component responsiveness.
